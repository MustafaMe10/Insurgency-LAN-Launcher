# Insurgency2014-LAN-Launcher
This is a Launcher that let's you play Insurgency 2014 LAN easily without just typing commands in the console. It wasn't made by me, Gemini (Google AI) made it. And after some edits and testing it worked! and i know just 1% of how to use HTML (this file is .hta)
# Features
* **Auto LAN IP Display:** Automatically fetches your active IPv4 address via `ipconfig` so you don't have to open CMD to find it.
* **Simple GUI Setup:** Select maps, game modes (PVP & Co-op), and languages from drop-down menus instead of typing launch arguments manually.
* **Randomizer:** Picks a random map and mode combination if you can't decide what to play.
* **Custom Map Support:** A simple prompt to input custom `.bsp` map names.
* **Single File (.hta):** Lightweight and runs natively on Windows using MSHTA without needing extra frameworks or installers.
# How To Use
### For Host (Server)
1. Download `Launcher.hta`.
2. Place `Launcher.hta` directly inside your main Insurgency game folder (where `insurgency.exe` is located).
3. Double-click `Launcher.hta`, select your map and mode, then click **LAUNCH GAME SERVER**.

### For Friends (Joining)
1. Make sure everyone is connected to the same Wi-Fi / local network.
2. Open Insurgency and open the console using the `~` key.
3. Type `connect <IP_SHOWN_ON_LAUNCHER>` and press Enter.
